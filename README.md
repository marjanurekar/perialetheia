# CWIAL No. 1 - website

Public site for the Cognitive Warfare Information Analysis Laboratory No. 1,
Faculty of Technical Sciences, University of Novi Sad.

**Live at:** https://marjanurekar.github.io/perialetheia/

## What this is

A single self-contained `index.html`. No build step, no framework, no external
requests - it works offline and will still work in ten years. Edit the file,
commit, and the live site updates within about a minute.

## Editorial rule

Every figure on this site is traceable to a named published source. Quantities
that have not been evaluated are shown as unevaluated rather than omitted or
estimated. If a number cannot be sourced, it does not go on the site.

## Files

| `index.html` | The entire site - structure, styling, and figures |

## Updating the monthly report

The report lives in `<section id="report">`. To publish a new one, replace the
contents of that section and update the `§7.8` line and the `<h2>`. Keep the
"Not yet measured" panel: it is the point of the site, not a placeholder.
